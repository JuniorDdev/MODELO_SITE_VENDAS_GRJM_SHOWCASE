# Modelo Site de Vendas — GRJM

> 🏆 Projeto campeão do **Módulo 1 da INCODE — 2025**.

Este é o repositório de showcase do **Modelo Site de Vendas GRJM**, uma vitrine digital de produtos de informática desenvolvida como projeto de conclusão do Módulo 1 da INCODE.

O projeto une apresentação comercial, catálogo visual e navegação web em uma experiência simples e direta. Esta página registra o reconhecimento conquistado pela equipe e direciona para a versão técnica preservada do trabalho.
